Updated 12 September 2026. Scores assess documented product depth, not scientific certainty or released-code completeness.

|---|---:|---:|---|
| Research base | 8/10 | 8.5/10 | Both are substantial; conditioning has more dedicated source mapping. |

| Implementation and validation proof | 4/10 | 4.5/10 | Both remain short of an end-to-end released, prospectively tested controller. |

## Verdict

Conditioning currently has greater visible system depth: approximately **8/10 versus 7/10 for strength**. The gap is smaller than the earlier ZIP implied. The archive previously made strength look closer to 3/10 because its work was buried rather than absent.

Strength is deeper in logger simplicity, exercise identity, prescription/result separation, set architecture and exercise-specific progression. Conditioning is deeper in named training methods, daily recovery integration, heart-rate zoning, modality control and session substitution.

The next useful strength work is not another broad research pass. It is converting the documented rules into one canonical decision table and test suite, then running it in shadow mode over the TrainHeroic history. Adding more prose without that integration would increase file count rather than product depth.
