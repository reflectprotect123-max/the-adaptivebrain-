# @adaptivebrain/kernel

Deterministic session kernel: `open`, `decideNext`, and `close`. No HTTP. No LLM. No athlete UI.

This package is the Brain decision hub only. Strength (TRACK) and Engine athlete apps live in sibling repos (`strengthside`, `Engine-side-`).

## Tests

From this directory:

```bash
npm test
```

Runs Node's built-in test runner against `test/*.test.js`.
